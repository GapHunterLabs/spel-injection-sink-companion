Reports a Spring ExpressionParser.parseExpression(...) call whose argument is built from an HTTP endpoint parameter, and a constant expression that references a dangerous type through T(...) (Runtime, ProcessBuilder, System).

Input that becomes SpEL source text is parsed and evaluated as code, which can lead to remote code execution (CWE-917), the mechanism behind CVE-2022-22963 in Spring Cloud Function. Keep user input out of expression text; use a SimpleEvaluationContext when an expression must be evaluated.
